# PWAMEDIA Website Starter

Herbruikbare Next.js-basis voor professionele PWAMEDIA-klantensites.

## Vaste basis

- Next.js + TypeScript
- Tailwind CSS
- Sveltia CMS op `/admin`
- GitHub als bron en versiebeheer
- Klaar voor automatische deployment op Vercel

## Lokaal starten

```bash
npm install
npm run dev
```

Open daarna `http://localhost:3000`.

## Volgende modules

Formulieren, Resend, Turnstile, database, uploads, login en betalingen worden als afzonderlijke, herbruikbare modules toegevoegd zodra de basis is goedgekeurd.
